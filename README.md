# market-distribution-tests

Five textbook distributions (Normal, Student-t, Bernoulli, Poisson, Uniform), each turned into a claim
about markets and tested out-of-sample on S&P 500 and KOSPI daily returns.

The full README, figures and results are generated by the first GitHub Actions run
(`.github/workflows/update.yml`). Run it locally with:

```bash
pip install -r requirements.txt
python scripts/run_all.py --refresh && python scripts/make_figures.py && python scripts/build_readme.py
```
